# DailyThoughts Journal — Landing Page

Welcome to the landing page for **DailyThoughts Journal**, a personal digital diary built with Ruby on Rails.

The project is designed to help you record daily thoughts, preserve memories, attach photographs, and build a personal archive of your life.

## Website

Visit the landing page:

https://pmnoos.github.io/diary_app-landing/

## Features

- Simple daily journaling
- Photo attachments
- Timeline and date-based archive
- Events and appointments
- Tags and organisation
- Self-hosting options
